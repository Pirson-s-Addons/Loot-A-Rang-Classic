## What it does
**Loot-A-Rang Classic** uses the **Loot-A-Rang** toy for you: double right-click on the game world and the toy is used, so you can loot corpses from a distance without searching for it in your bags or bars.

## Features
- Double right-click (within 0.3 s) on the world uses the Loot-A-Rang.
- Only out of combat.
- Creates or updates a character macro called `LootARangMacro` (`/use Loot-A-Rang`) on login, in case you want it on a bar.
- Uses the localized toy name, so it works on any client language (20 languages).

## Installation
1. Download the zip from the [latest release](https://github.com/Pirson-s-Addons/Loot-A-Rang-Classic/releases/latest) or from [CurseForge](https://www.curseforge.com/wow/addons/loot-a-rang-classic).
2. Extract the `LootARangClassic` folder into `World of Warcraft/_classic_/Interface/AddOns/`.
3. Restart WoW and enable the addon.

## Usage
- `/lar on` — enable the double right-click.
- `/lar off` — disable it.
- `/lar help` (or just `/lar`) — list the commands.
- `/lootarang` works the same as `/lar`.

## Notes
- You need the Loot-A-Rang toy.
- The on/off setting is not saved: the addon is enabled again every time you log in.
